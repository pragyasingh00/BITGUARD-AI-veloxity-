# AI Detection Layer

This module will contain the AI/ML components responsible for detecting anomalous and suspicious Bitcoin transaction behavior.

## Planned Responsibilities

- Transaction feature engineering
- Behavioral analysis
- Anomaly detection
- Risk classification
- Model evaluation
- Explainable risk signals

## Planned Models

- Isolation Forest for unsupervised anomaly detection
- XGBoost for behavioral classification

## Validation

Models will be evaluated using:

- Elliptic / Elliptic++ dataset
- Proxy known-bad wallet/address intelligence
- False-positive rate
- Precision and recall where labeled data is available
