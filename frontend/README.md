# Investigation Dashboard

This module will provide the web interface for monitoring Bitcoin transaction activity and reviewing AI-generated investigation results.

## Planned Responsibilities

- Real-time transaction monitoring
- Suspicious activity alerts
- Risk score visualization
- Transaction and wallet graph visualization
- Evidence and signal inspection
- Investigation timeline
- Investigation report generation

## Planned Technology

- React
- TypeScript
- Tailwind CSS
- WebSockets
- Graph visualization library

## Core Dashboard Views

- Live Transaction Monitor
- Risk & Alert Dashboard
- Entity / Transaction Graph
- Investigation Details
- Explainable Risk Assessment
- Investigation Report

**Planned — MVP development**
