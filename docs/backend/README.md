# Backend

This module will provide the backend services for BITGUARD AI.

## Planned Responsibilities

- Bitcoin transaction data ingestion
- Mempool and block data processing
- Transaction feature extraction
- Risk-analysis API endpoints
- Communication between AI, graph, and investigation modules
- Real-time updates to the frontend

## Planned Technology

- Python
- FastAPI
- PostgreSQL
- Redis
- WebSockets
