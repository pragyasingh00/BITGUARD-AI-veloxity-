# Blockchain Graph Intelligence

This module will represent and analyze relationships between Bitcoin transactions, wallet addresses, and related entities.

## Planned Responsibilities

- Transaction graph construction
- Wallet relationship analysis
- Address clustering
- Transaction flow analysis
- Fan-in / fan-out detection
- Graph expansion around suspicious entities
- Network centrality and connectivity analysis

## Planned Technology

- NetworkX
- Neo4j
- PostgreSQL

## Investigation Role

The graph layer will provide relationship evidence to the investigation agent, helping connect seemingly separate transactions and entities.
